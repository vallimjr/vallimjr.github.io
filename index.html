GERENCIAR CANAIS

Cole um ou vários canais (um por linha ou separados por vírgula). Pode ser @handle ou link: @canal, https://www.youtube.com/@canal, https://www.youtube.com/channel/UC.... Custa 1 unidade por canal.

BUSCAR CANAIS POR TEMA

Cada busca gasta 100 das 10.000 unidades do dia.

INDICADOS PELOS CONCORRENTES

Lê os "canais em destaque" de cada concorrente e mostra os mais citados. Custa 1 unidade por canal do radar. Muitos canais não indicam ninguém; nesse caso a lista vem pequena.

MESA "VOCÊ": APROVAÇÃO DE PAUTAS

No Radar, clique em + Pauta num vídeo que foi bem. Aqui você aprova ou pede revisão. O botão Copiar prompt copia um pedido de títulos pronto para colar no Claude.

AGENDA SEMANAL

As pautas aprovadas entram aqui quando você escolhe um dia para elas (na aba Pautas, em Aprovadas).

CHAVE DA API DO YOUTUBE

A chave fica guardada só neste navegador (localStorage). Ela não vai para o GitHub nem para nenhum outro lugar, só para o próprio YouTube (googleapis.com) em cada consulta.

ESTILO DO MEU CANAL (PARA O PROMPT)

Opcional. Cole de 3 a 6 títulos reais do seu canal, um por linha. Eles entram no "Copiar prompt" como exemplo de estilo.

CÓPIA DE SEGURANÇA

Salva os canais, as pautas e a agenda num arquivo (sem a chave). Serve para levar para outro computador ou navegador.
